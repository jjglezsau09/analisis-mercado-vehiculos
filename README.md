# 📊 Análisis del Mercado de Vehículos

## 🧠 Objetivo
Analizar el mercado de compra y venta de vehículos para identificar tendencias de precios, demanda y comportamiento del mercado.

## 📂 Dataset
Datos relacionados con vehículos en venta, incluyendo precios, modelos, año y características.

## 🧹 Limpieza de datos
- Eliminación de valores nulos  
- Estandarización de datos  
- Filtrado de registros inconsistentes  

## 📊 Análisis realizado
- Distribución de precios  
- Análisis por tipo de vehículo  
- Relación entre año y precio  
- Tendencias del mercado
